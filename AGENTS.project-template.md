# <project> agents

## Issue tracking

Tracker: GitHub issues. (Global agents file covers how to keep them in sync.)

- Task slug: branch `<type>/<issue>-<slug>`, commits reference `#<issue>`.
- Labels: pick from `type:` (feat/fix/chore/docs), `area:*`, `priority:` (low/med/high).
- Status: `todo` → `in progress` → `review` → `done`; move the label as work moves.
- Done means: acceptance criteria met and linked PR merged.
